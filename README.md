Project Overview
The Student Attendance Management System is a UI/UX design project created to provide a simple and organized way to manage student attendance. The design includes separate interfaces for Admin, Staff, and Students, along with attendance tracking and percentage monitoring.
Objectives
Manage student and faculty information.
Record and monitor daily attendance.
Provide separate access based on user roles.
Display student attendance percentages.
Make attendance management simple and user-friendly.
